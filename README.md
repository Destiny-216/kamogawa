

SDGs × 鴨川　野生動物紹介サイト

本プロジェクトは、SDGs（持続可能な開発目標）のうち  
「SDGs15：陸の豊かさを守ろう（生物多様性の保全）」をテーマに、  
京都・鴨川周辺に生息する野生動物や自然環境を紹介する Web サイトです。

環境問題や生物多様性といった社会的テーマを、  
Web を通して分かりやすく、視覚的に伝えることを目的として制作しました。

---

制作背景・目的

大学の課題および個人学習の一環として、  
以下の点を意識して取り組みました。

・SDGs の理念を、身近な地域（鴨川）と結び付けて考えること  
・専門知識がなくても理解できる情報構成にすること  
・テキスト中心ではなく、視覚的に伝わる Web 表現を意識すること

技術的な高度さよりも、  
テーマ設定・構成・情報の伝え方を重視したプロジェクトです。

---

使用技術

・HTML  
・CSS  
・JavaScript

フレームワークは使用せず、  
基本的な Web 技術のみで構成しています。

---

主な内容

・鴨川周辺に見られる野生動物の紹介  
・生物多様性と SDGs15 との関連付け  
・写真とテキストを組み合わせた情報整理
